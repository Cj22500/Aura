# Aura Living & Acoustics - Full-Stack E-Commerce Storefront & Developer Inspector

A full-stack e-commerce storefront and interactive engineering showcase built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **Node.js / Express (`server.ts`)**, and **WebSockets (`ws`)**.

## Key Features
- **Complete E-Commerce Storefront & Cart State Management**: Product catalog filtering, dynamic shopping cart calculation, stock validation, and multi-step checkout state flows.
- **REST CRUD & Real-Time WebSocket Updates**: Full backend Express API handling product inventory, order creation, and live state synchronization.
- **Interactive Developer Inspector**: Built-in inspector mode allowing technical reviewers to inspect live API payloads, state transitions, and validation rules in real time.

## Tech Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Vite, Framer Motion, Lucide React
- **Backend**: Node.js, Express (`server.ts`), WebSockets (`ws`), `@google/genai`

## Local Setup
```bash
npm install
npm run dev
```
